# 03-Design-System Directory

This directory contains the specifications, design tokens, and components that make up the Sentinel Design System (SDS).

## Subdirectories

- `tokens/` - JSON configurations defining the design tokens (colors, spacing, typography, shadows, borders).
- `components/` - Specifications for individual UI controls (buttons, cards, badges, panels, inputs).
- `specifications/` - Detailed documents defining the design system rules.

## Core Documents

- `spec_003_design_language.md` - Core UI philosophy, visual hierarchy, density guidelines, and terminology guidelines.
- `spec_003_5_design_system.md` - SDS golden rules, spacing grids, typography levels, and component definitions.
