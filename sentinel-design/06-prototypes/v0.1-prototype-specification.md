# 1. Product Manifesto: "Engineering deserves better tools."

## Why Sentinel Exists

Software engineers have some of the most powerful tools in the world, yet many code quality tools feel like they were designed for compilers rather than for people. They expose diagnostics instead of guidance, warnings instead of priorities, and configuration instead of clarity. Sentinel exists to change that.

## Our Core Beliefs

Code quality should be:

- **Understandable, Actionable, Fast, Offline, Transparent, and Beautiful.**

Sentinel integrates and supports the tools developers already love; it does not replace them. It respects developers' time and focus, and aims to quietly help rather than interrupt.

---

# 2. Main Value Proposition of Sentinel 1.0

Sentinel 1.0 has exactly **one job**:

> **Help a developer understand whether their code is ready to commit and make it easy to improve it.**

We defer organization dashboards, marketplace integrations, compliance suites, and multi-language support to versions 2.0 and 3.0.

---

# 3. Key Concept: The Knowledge Graph

Instead of a simple database list of files, Sentinel constructs an internal relational Code Knowledge Graph:

```text
Project
  └── Modules
        └── Folders
              └── Files
                    └── Symbols (Classes, Functions)
                          ├── Dependencies
                          ├── Rule Matches (Issues)
                          └── Commit History
```

This graph calculates exact quality scores, dependencies, risk margins, and impact. For example, if a developer changes `Logger.cpp`, Sentinel immediately identifies that the dependent `Network.cpp` is affected and updates its ready state.

---

# 4. User Modes

The prototype must support three viewpoints:

1. **Developer Mode:** Focuses on the immediate scan-and-fix loop (Overview, Issues, safe Autofixes).
2. **Reviewer Mode:** Compares pull requests and branch changes (PR quality delta, diff comparisons).
3. **Architect Mode:** visualizes folder heatmaps, dependency trees, and long-term quality trends.
