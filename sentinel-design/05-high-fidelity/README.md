# 05-High-Fidelity Directory

This directory contains high-fidelity design specifications, screen mockups, assets, and design links for Sentinel.

## Subdirectories

- `mockups/` - Rendered PNG/SVG screenshots of each screen layout.
- `assets/` - Logo assets, color palettes, and SVG icons.
- `figma_links.md` - Links to design files, components, and templates in Figma/Sketch.
